# The Obsidian Estate — rsfrazier.com

This is not a website. It is one continuous explorable environment — the
digital front door to the world of R.S. Frazier: the music, the books, the
style, the magazine, and the Estate itself.

Built per the **Canon Update Brief (August 2026)**, which supersedes earlier
documentation wherever they conflict.

## How it works

- **No pages.** The whole Estate is a single environment (`index.html`).
  Every room is a scene; moving between rooms is a cinematic transition,
  not a page load. Deep links work (`/#/grand-atrium`), and Netlify
  redirects every route back into the environment.
- **The architecture is the interface.** Navigation is embedded in the
  rooms as gold hotspot rings. There is no nav bar, no menu, no footer.
- **Canonical District IV sequence** (locked):
  Security Gate → Founder's Way → Legacy Circle → Central Fountain Court →
  Grand Atrium → Onyx Lounge → Library → Hall of Legacy → Founder's
  Gallery → Morning Room → Chef's Kitchen → Formal Dining → Conservatory
  Gallery → Rear Estate.
- **The Onyx Lounge** is the orientation space (replaces a homepage): room
  index, Guest Book (the Gemini reservation list begins here), and a hint
  that not every room is listed.
- **The secret Gemini entrance** lives in the Library behind the
  *Discover more* hotspot: four cutscenes — the bookshelf
  (*Manchild in the Promised Land*, Claude Brown, clue **1984** = 8 rows
  down, 4 books across, plaque: "Never stop dreaming… even when the world
  wants you to."), the shelf opening, the unbranded corridor, the walk
  toward the red glow — and only then the Gemini reveal. Discovery
  persists in `localStorage`, after which Gemini appears in the Onyx
  Lounge index under "DISCOVERED."

## The RSF crest — IMPORTANT

The crest is **never drawn or regenerated by code**. Drop the approved
canonical shield asset at:

```
assets/crest/rsf-shield.png
```

(transparent PNG recommended). Every crest location (Grand Atrium floor,
Founder's Gallery wall) is a `crest-slot` that renders the canonical file.
Until the file exists, slots display a clearly-marked placeholder ring —
a stand-in, not a redrawn crest.

## Sound

Off by default; toggled top-right. All ambience is synthesized (WebAudio)
room tone — no audio assets required. When real recordings exist (jazz for
the Gemini corridor, fountain water, hearth crackle), drop them in
`assets/audio/` and wire them in `js/estate.js` (`sceneAmbience`).

## Guest Book

A Netlify form (`guest-book`) — submissions appear in the Netlify
dashboard under Forms once deployed. No backend required.

## Structure

```
index.html        every scene in the environment
css/estate.css    the design system (obsidian, gold, warm light)
js/estate.js      scene engine, cutscene sequencer, sound, guest book
assets/crest/     canonical RSF crest asset (supplied, never redrawn)
netlify.toml      publish config + route redirect
```

## Future districts

District III (Gemini) will grow behind the discovery flow: password entry,
host greeting, reservations, cocktail experiences, events, private rooms.
It should never be reachable through obvious navigation — only through
discovery. Districts I, II, and V are not yet built in the environment.
